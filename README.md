# CreateSityAmursk — обновлённая версия

Статический адаптивный сайт. Не требует сборки, npm или backend.

## Запуск
Откройте `index.html` в браузере или загрузите все файлы в корень GitHub Pages.

## Перед публикацией
1. Откройте `config.js`.
2. Укажите Telegram username без `@` в `telegramUsername`.
3. Если username пока не указан, форма откроет Telegram Share: посетитель сам выберет чат и отправит подготовленный текст. Это не автоматическая доставка заявки владельцу.
4. Замените демонстрационные концепции портфолио реальными работами по мере появления.
5. Не добавляйте вымышленные отзывы. Разместите отзывы только с согласия клиентов.

## Состав
- `index.html` — страницы и контент
- `style.css` — дизайн и адаптивная сетка
- `script.js` — меню, предзаполнение услуги, обработка формы
- `config.js` — настройки контакта Telegram

## Публикация на GitHub Pages
Замените файлы в репозитории `createsityamursk/CreateSity` и дождитесь завершения GitHub Pages deployment.
